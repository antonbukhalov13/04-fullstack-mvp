## Что нужно сделать

Разработать fullstack MVP учебного финансового сервиса LumenBridge Finance Ltd на основе клиентского текста и ТЗ: сайт с онлайн-заявками на краткосрочные займы для физлиц и малого бизнеса в Европе, калькулятор условий займа, форма заявки, личный кабинет пользователя со входом по номеру телефона через имитацию SMS OTP и административная панель с ролями admin/operator. Проект должен показывать полный путь заявки: от подачи через форму до одобрения, подписания займа, графика платежей, ручной фиксации платежей и закрытия займа. Backend — реальный, данные сохраняются в PostgreSQL; реальные платежные интеграции, SMS-провайдер и скоринг заменяются локальными mock-сценариями.

## Стек

Frontend: Next.js (App Router), React, TypeScript, Tailwind CSS v4, React Hook Form для формы, Valibot для схемы валидации, архитектура Feature-Sliced Design. Backend: Node.js, NestJS, PostgreSQL. Frontend и backend связаны по HTTP, URL backend — в переменной окружения, CORS настроен. Клиентская и серверная валидация обязательны.

## Что должно получиться

- лендинг и публичные страницы: главная (hero, калькулятор, условия займа, преимущества, о компании, блок для бизнеса, FAQ-превью, форма обратной связи, контакты), страница "Как это работает", страница "Для бизнеса", страница FAQ, privacy policy, cookie policy
- калькулятор займа по аннуитетной формуле с дневной ставкой 0.8%
- форма заявки (физлицо/бизнес): react-hook-form + valibot, клиентская и серверная валидация, состояния success/error
- backend на NestJS + PostgreSQL: пользователи, заявки, займы, графики платежей, платежи, заявки на оплату, уведомления, сообщения обратной связи; загрузка документов (для бизнес-заявок и вложения формы обратной связи) — реальная интеграция с S3-совместимым хранилищем
- вход пользователя через mock SMS OTP, вход администратора по логину/паролю, роли admin и operator
- личный кабинет: заявки, займы (активные/закрытые), карточка займа с графиком платежей, подписание займа через OTP, заявка на оплату, уведомления
- административная панель: заявки, клиенты, займы, платежи (проверка заявок на оплату и ручная фиксация платежей), уведомления, поиск и фильтры, разграничение прав admin/operator
- адаптивная верстка под мобильные и планшетные экраны
